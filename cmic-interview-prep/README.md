## 🗓️ 4일 계획 (총 12시간)

### Day 1 (3h) — Java + OOP 영어 답변

- Hour 1: `02-java-basics.md` 17주제 코드 직접 타이핑 + 영어 스크립트 3번씩 말하기
- Hour 2: `03-coding-practice.md` 3문제 풀고 영어로 설명
- Hour 3: `04-oop-english.md` 5개 답변 외우기 + 약한 주제 다시 타이핑

### Day 2 (3h) — SQL/PL-SQL ★ 핵심 ★

- Hour 1: `06-sql-basics.md` — SELECT / JOIN / GROUP BY / HAVING / window function
- Hour 2: `07-plsql.md` — PL/SQL 블록, cursor, exception handling, procedure
- Hour 3: `08-sql-tuning.md` — 실행계획 + 인덱스 + 튜닝 + 운영지원 답변

### Day 3 (3h) — J2EE 스택

- Hour 1: JDBC + Connection pool + Transaction + PreparedStatement
- Hour 2: JSP / Servlet / MVC + REST / JSON (Jersey, ADF BC 스타일)
- Hour 3: 운영 지원 / 트러블슈팅 시나리오 답변

### Day 4 (3h) — Mock Interview

- Hour 1: 약점 재훈련
- Hour 2: 풀 모의면접
- Hour 3: 마무리 정리 + reverse questions 영어 답변
