# 2-Hour Final Drill (면접 직전 압축)

코드 + 10번 말하기 + 팔로우업 단답.

---

## ⏰ 2시간 구성

| 구간 | 시간 | 내용 |
| --- | --- | --- |
| **Hour 1** | 60분 | 코딩 15개 (각 4분) — 백지부터 직접 짜고, 다 짠 다음 한 줄 영어 10번 말하기 |
| **Hour 2** | 60분 | `one-liners.md` 30개 — 각 2분 (읽고, 닫고, 10번 말하기) |

---

## 🎯 절대 규칙

1. **코드는 백지에서.** 정답 파일 보지 마세요. 막혀도 5분은 끙끙.
2. **말하기는 소리내어.** 머릿속으로 말하면 면접에서 막힘. 입을 움직이세요.
3. **10번 다 카운트.** 파일 안에 체크박스 있음.
4. **팔로우업도 입으로.** "What if...?" 한 마디 더 던졌을 때 답할 수 있게.
